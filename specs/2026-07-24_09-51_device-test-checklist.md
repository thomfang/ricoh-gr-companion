# RICOH GR Companion 1.0.0 真机测试清单

> 目标设备优先级：RICOH GR IIIx / 固件 1.21。请严格按编号逐项执行；每完成一项就把该项的“反馈模板”发回，不必等全部完成。

## 测试安全约束

- 不要发送相机 WLAN 名称、密码、序列号或私人照片。
- 只需反馈相机型号、固件版本、步骤结果、界面文案、HTTP 状态及脱敏后的 JSON 字段名/结构。
- 本应用不应执行相机侧 PUT、POST、DELETE，不应删除照片或改变相机传输标记。
- 如果出现明显发热、应用卡死、重复保存大量照片或相机异常，请立即停止当前步骤并反馈。

## 统一结果标记

- `PASS`：表现与预期一致。
- `FAIL`：可稳定复现且与预期不一致。
- `BLOCKED`：因权限、网络、设备状态等无法继续。
- `SKIP`：设备上没有对应格式或场景，例如没有 DNG/视频。

2. 立即再次点击开始。

4. 等待 3 秒，再进入 LiveView 并重新开始。

- 离开页面会自动停止。

## 15. 最终回归与 1.0.0 判定

### 操作

1. 关闭并重新打开脚本。
2. 确认照片库仍可刷新。
3. 确认单张 JPEG 仍可保存。
4. 确认 LiveView 仍可开始和停止。
5. 汇总所有 `FAIL/BLOCKED/SKIP`。

### 1.0.0 通过条件

- GR IIIx 1.21 上照片列表、JPEG 缩略图和详情可用。
- 单张 JPEG 到 Photos 与 Files 均成功，画面、方向、分辨率正常；日期/EXIF 的保真情况已有明确结论。
- Files 同名不覆盖，取消和网络失败后 UI 可恢复。
- 多选具有逐项终态且仅处理用户选择内容。
- LiveView 单连接、停止、离页释放和重启回归通过。
- 没有相机侧写入、删除、凭据读取或隐私泄露证据。

### 仍不能声明完成的情况

- 只通过离线测试但没有上述 GR IIIx 真机证据。
- 照片可以打开，但日期、方向、分辨率或 EXIF 尚未核对。
- 取消/失败后界面卡在运行中。
- 诊断或反馈包含敏感信息。
- GR III/GR IV 尚无对应设备证据时，不声明其完整兼容。
